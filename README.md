# Pulso Polar · Auroras y campo magnético

**Ver el sitio en vivo:** https://karina0305.github.io/Pulso-Polar/

Interacción visual de las auroras y la actividad geomagnética, con datos en tiempo real de NOAA SWPC.

## Pantallas
- `index.html` — 01 · Lo que produce el pulso (portada).
- `pantalla2.html` — 02 · Siente el pulso (onda Kp, latidos y cámara).
- `pantalla3.html` — 03 · El pulso que nos protege (reflexión).

## Verlo en local
Abre `index.html` en tu navegador, conservando las carpetas `css`, `js` y `assets` junto a él. No requiere instalación. La consulta a NOAA requiere internet.

## Datos
Fuente: https://www.swpc.noaa.gov/products/planetary-k-index
